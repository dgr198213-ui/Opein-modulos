# Datos de catálogo para fabricación

## Fuente archivada del usuario

La página 38 del catálogo adjunto identifica las siguientes referencias de módulos: `CAS6MDIA.01` para módulo estándar, `CAS6MDBA.01` para módulo con sanitario y `CAS1MSAN.01` para módulo con duchas. La misma ficha describe una estructura reforzada, paneles galvanizados y aislamiento térmico de poliuretano, pero no suministra despieces estructurales, medidas de perfiles, tipos de tornillería, grado de acero ni proveedores de componentes.

## Contraste con la web oficial de Opein

La web oficial confirma `CAS6MDIA.01` como módulo diáfano de 6 m y `CAS6MDBA.01` como módulo con aseo lateral. Para el módulo de 6 m con 4 duchas y 2 aseos, la referencia vigente publicada es **`CAS6MSAN.01`**, no `CAS1MSAN.01`; tiene dimensiones de **6.000 × 2.440 × 2.700 mm** y se describe con 4 duchas individuales, 2 aseos y lavamanos. La página incluye además referencias relacionadas aplicables al catálogo: `MLTAQUILL.01` (taquillas), `MLTAQUILL.02` (taquillas de plástico) y `MLMESAOFI.03` (mesas plegables).

## Aplicación en el configurador

Se conservará el SKU actual `CAS6MSAN.01`, al ser el código vigente y verificable del proveedor. Los datos que no están publicados —métrica y grado de tornillería, perfiles, esquineras, proveedor específico de cada componente y cantidades de fabricación— se crearán como campos editables y se exportarán como atributos de bloque, inicializados como `N/D` cuando no se pueda confirmar una fuente.
